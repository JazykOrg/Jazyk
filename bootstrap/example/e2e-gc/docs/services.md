# Services

The Platform is built from sixteen services. The services share the stores of the Data Layer described in [Storage](./storage.md).
The Reporting service exports the Order Audit Trail. The Order Audit Trail lists every charge for the auditor.

## Storefront

The Platform contains the Auth service. The Platform contains the Catalog service.
The Platform contains the Search service. The Platform contains the Cart service.
The Platform contains the Checkout service. The Platform contains the Pricing service.
The Platform contains the Promotion service. The Platform contains the Review service.

## Back Office

The Platform contains the Billing service. The Platform contains the Inventory service.
The Platform contains the Shipping service. The Platform contains the Notification service.
The Platform contains the Analytics service. The Platform contains the Reporting service.
The Platform contains the Support service. The Platform contains the Fraud service.
