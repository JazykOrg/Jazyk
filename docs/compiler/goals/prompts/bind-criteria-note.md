Each criterion needs a separate test declaration named by suggestedTestName. A requirement without criteria uses one statement-level test. Test functions may share source files and an ordinary project suite across requirements. For run="task:<id>", reuse that saved suite task and put the exact JUnit classname::name (or unique case name) in name. The task command may run the whole suite; each report case supplies its own criterion verdict. Only a legacy command judged by its exit code must select one test. A requirement or criterion does not need its own task, test file or container.
