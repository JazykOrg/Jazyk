# Small prompt fragments

Each file explains its surrounding workflow and identifies its consumer in
frontmatter. Purpose, trigger conditions, and argument meanings belong there when
they add a distinct explanation. These are small tool
instructions and corrective messages, so headings usually belong in their source
context rather than the rendered message.

Rust format slots are filled once by the consumer after source preparation. Keep
the slots aligned with the consumer arguments. Filenames combine a descriptive
opening with a short digest to distinguish similar messages.
