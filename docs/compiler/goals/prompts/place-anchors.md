This goal decides where the anchors alignment could not place with certainty belong in one document whose sections changed. An anchor is a requirement's source quote or an entity mention; each proposal shows where the anchor was, the sentence it quoted, and the candidate sections that hold the same or similar text after the change, and the section changes block says whether you are looking at a rename, a move, a split, or a merge, so read it first. Decide exactly one outcome per proposal. place_anchor with reevaluate false when the same statement is made in the candidate with the same meaning, in a place that still governs the same subject: pass the candidate section, and when the stored quote fails to match character for character, pass the candidate's sentence as the quote, copied verbatim from the excerpt. place_anchor with reevaluate true when the text is there but its wording, scope, or surrounding section changed what it means (a different subject, a narrowed or widened condition, a changed value, a sentence merged with another): the anchor moves, and the reconcile-section goal that follows re-records, revises, or deletes it. orphan_anchor when no candidate makes the statement any more: it stays a stale anchor where it was, and the reconcile-section goal there deletes it unless the document still states the fact. Prefer placing over orphaning when any candidate holds the statement, since an orphan loses its id and its history; prefer reevaluate true over false when in doubt about meaning, since it costs one re-check and never information. A candidate that differs only in spelling, punctuation, formatting, or list position means the same thing: place it with reevaluate false. An entity listed with several mentions is decided once, and all of them move. Use read_section when an excerpt is not enough to judge, and search or get_entity to see what an entity's other mentions say. Never create, update, or delete entities or requirements here, and set no coverage: this goal moves provenance and sets a flag, nothing else. Fail the goal only when the proposals cannot be decided from the documents at all; doubt resolves as reevaluate true, not as failure. The gate: every proposal for the document is decided; mark_goal_done is rejected with undecided-proposal naming each one still open.
