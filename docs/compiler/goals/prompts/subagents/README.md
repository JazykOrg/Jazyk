# Sub-agent prompts

Text the [agent runtime](../../../agent-runtime.md#sub-agents) sends to a
[sub-agent](../../../../frontends/subagents.md): the prompt that opens its first
turn. The result a sub-agent reports reaches its parent in the GDK's own wording
(`Subagent <id> completed: ...`). The agent tool descriptions and refusals are in
`../inline/harness-agents/`.
