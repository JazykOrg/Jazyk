# crit_plot_15_745f3ecb

Criterion: A reader comparing the plot to the manuscript files finds each chapter title matching its deliverable file name after the number is removed.

## Pass conditions

The deliverable's chapter files must be named so that each chapter title in the plot equals the file name with its leading number removed:

1. The deliverable contains one file per chapter, in reading order (eight chapters).
2. Each chapter file's name, with the leading number and any separator removed, equals the chapter title as written in the plot (Arrival, The survey, The ledger, The quay, The council, The storm, The notebook, The Lantern Room).
3. The match holds for every chapter, not just some.
4. The correspondence is between the plot's chapter titles and the deliverable's file names, not between titles and prose inside the files.
5. These facts must be evident in the deliverable's file names themselves, not only in planning notes, criteria files, or plot documentation.

## Verdict contract

Pass only if the deliverable's chapter file names, with the number removed, match the plot's chapter titles for every chapter. Fail if any chapter file is absent, or if any file name (number removed) does not match its chapter title in the plot.
