# crit_plot_19_a08c4613

Requirement: req:plot-28
Statement: Theo Brandt's field notebook contains measurements that he wrote down twice.

Criterion: In Chapter 7, Ines reads Theo's field notebook and finds measurements Theo wrote down twice.

## Pass conditions

The manuscript must contain a Chapter 7 field-notebook scene in which Ines finds twice-written measurements:

1. The scene occurs in Chapter 7 or is clearly part of the Chapter 7 sequence.
2. Ines Marlow is present and reads Theo Brandt's field notebook.
3. The field notebook contains measurements written by Theo Brandt.
4. The measurements are shown or clearly described as having been written down twice.
5. Ines discovers or recognizes the duplicated measurements by reading the notebook herself.
6. These facts must be evident in manuscript content, not only in planning notes, criteria files, or character documentation.

## Verdict contract

Pass only if the completed manuscript satisfies all pass conditions. Fail if Chapter 7 does not contain the notebook-reading scene, Ines does not read the field notebook herself, the measurements are not Theo Brandt's, or the text does not show that the measurements were written down twice.
