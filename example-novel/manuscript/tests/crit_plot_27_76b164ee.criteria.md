## Pass conditions

The manuscript must contain prose corresponding to every scene line from the plot source. A reviewer must be able to match each source scene line to prose in the manuscript, and that prose must preserve the named action without adding a different event.

## Verdict contract

Pass if the manuscript prose covers every scene line and preserves each named action without adding a different event. Fail if manuscript prose is absent, if any scene line has no matching prose, or if any matching prose changes what happens.
