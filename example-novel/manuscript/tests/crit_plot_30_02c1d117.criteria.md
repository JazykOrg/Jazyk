# crit_plot_30_02c1d117

Requirement: req:plot-38
Statement: The notebook scene's setting is the upstairs room of the Lantern Room.

Criterion: A reader of the notebook scene sees the upstairs room of the Lantern Room named as the scene setting.

## Pass conditions

The manuscript must contain a notebook scene set in the upstairs room of the Lantern Room:

1. The notebook scene exists as identifiable manuscript content.
2. The scene involves Theo Brandt's field notebook or is otherwise the same notebook scene named by the requirement.
3. The scene's setting is identified as the upstairs room.
4. The upstairs room is identified as part of the Lantern Room, or the surrounding manuscript context makes that connection clear to a reader.
5. These facts must be evident in manuscript content, not only in planning notes, criteria files, or character documentation.

## Verdict contract

Pass only if the completed manuscript satisfies all pass conditions. Fail if the notebook scene is absent, the setting is not the upstairs room, the upstairs room is not tied to the Lantern Room, or the setting appears only outside manuscript content.
