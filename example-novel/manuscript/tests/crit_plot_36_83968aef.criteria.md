# crit_plot_36_83968aef

Statement: Scenes inside a chapter run in the order listed.

Criterion: Within each chapter, the manuscript presents the chapter's scenes in the same order as the plot lists them.

## Pass conditions

The manuscript must preserve the plot order of scenes inside every chapter:

1. Each manuscript chapter that corresponds to a plot chapter exists as manuscript content.
2. Within each chapter, the identifiable manuscript scenes appear in the same relative order as the scene bullets for that chapter in `docs/plot.md`.
3. No scene from a later bullet appears before a scene from an earlier bullet in the same chapter.
4. No extra inserted scene changes the sequence of listed events inside a chapter.
5. The ordering must be evident from manuscript content, not from planning notes, test criteria, or file names alone.

## Verdict contract

Pass only if the completed manuscript satisfies all pass conditions. Fail if manuscript chapter content is absent, if any chapter's scenes are reordered relative to the plot, or if the only evidence of ordering is outside the manuscript itself.
