Criterion: A reader sees the character's name printed as `Ines` and not as `Inés`.

## Pass conditions

The manuscript must print the character's name without an accent:

1. The manuscript includes narrative content, not only test or criteria files.
2. Every occurrence of the character's name in the manuscript is printed as `Ines` (no accent on the e).
3. No occurrence of the name is printed as `Inés` (with an acute accent on the e).
4. No surrounding passage, heading, or byline contradicts the unaccented spelling.

The requirement is a constraint: the name must never appear with an accent. A passage that prints the name as `Inés` violates the criterion.
