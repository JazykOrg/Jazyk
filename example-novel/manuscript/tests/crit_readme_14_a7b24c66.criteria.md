Criterion: A project reviewer finds one markdown file for each chapter inside `manuscript/`, with that directory beside the bible.

## Pass conditions

The deliverable must be the manuscript itself: a directory called `manuscript/` (the deliverable directory) holding one markdown file per chapter, in reading order, beside the bible.

To pass:

1. The deliverable directory is the `manuscript/` directory, sitting beside the bible.
2. It contains one markdown file for each chapter the bible describes, in reading order.
3. The directory holds the chapter files themselves, not only test or criteria files.

The requirement is a structural constraint on the deliverable's layout. A directory that holds only test or criteria files, or that omits a chapter file, violates the criterion.
