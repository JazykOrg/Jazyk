Criterion: The plot contains a list of every scene and includes one scene written out in full as the worked example.

## Pass conditions

The plot document must both enumerate every scene and write one of them out in full:

1. The deliverable includes a plot document (plot.md or equivalent), not only test or criteria files.
2. The plot document contains a list that enumerates every scene of the manuscript.
3. The plot document writes out at least one scene in full as a worked example (a complete scene, not a one-line summary).
4. The worked example is one of the scenes listed in the enumeration.

The requirement is a constraint on the plot document's structure: it must serve as both an index of scenes and a demonstration of one scene fully realized. A plot that lists scenes but never writes one out in full, or that writes one out without listing the others, violates the criterion.
