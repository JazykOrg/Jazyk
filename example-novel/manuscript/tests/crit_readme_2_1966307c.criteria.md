# crit_readme_2_1966307c

Criterion: A maintainer resolving a manuscript-and-bible disagreement changes the bible before treating the manuscript as corrected.

## Pass conditions

The deliverable must show or prescribe the disagreement-resolution behavior where the bible is changed first before the manuscript is treated as corrected.

To pass:

1. The manuscript deliverable includes content or maintainer-facing material that addresses a disagreement between the manuscript and bible.
2. That content requires the bible to be fixed first when such a disagreement is found.
3. The manuscript is not presented as corrected until after the bible has been fixed.
