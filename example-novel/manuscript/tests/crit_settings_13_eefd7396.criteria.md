# crit_settings_13_eefd7396

Requirement: req:settings-12
Statement hash: 44f6c87277a2c699

Criterion: A reader sees the Lantern Room's name tied to the ship's lantern hanging in the front window.

## Pass conditions

The manuscript must establish the origin of the Lantern Room's name:

1. The manuscript identifies the Lantern Room by name.
2. The manuscript presents a ship's lantern hanging in the Lantern Room's front window.
3. The manuscript ties the name "Lantern Room" to that ship's lantern (the name comes from the lantern).
4. No surrounding passage contradicts the name being derived from the ship's lantern in the front window.

## Verdict contract

Pass only if the completed manuscript itself satisfies all pass conditions. Fail if the fact appears only in criteria files, planning notes, or source requirements, or if the manuscript does not tie the Lantern Room's name to the ship's lantern hanging in its front window.
