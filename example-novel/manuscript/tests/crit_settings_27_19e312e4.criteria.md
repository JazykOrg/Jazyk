Criterion: In the upstairs room, Theo finds the crack directly beneath the room's single window facing the harbor.

## Pass conditions

The manuscript must establish, in the upstairs room of the Lantern Room:

1. The upstairs room is identified as having one window, and that window faces the harbor.
2. Theo finds a crack in the room.
3. The crack is located directly beneath that single window.
4. No surrounding passage contradicts the room having a single harbor-facing window or the crack running beneath it.

## Verdict contract

Pass only if the completed manuscript itself satisfies all pass conditions. Fail if the fact appears only in criteria files, planning notes, or source requirements, or if the manuscript does not establish that the upstairs room has one harbor-facing window with the crack Theo finds running directly beneath it.
