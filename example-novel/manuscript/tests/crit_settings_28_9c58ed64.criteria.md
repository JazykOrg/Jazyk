# crit_settings_28_9c58ed64

Requirement: req:settings-20
Statement hash: 1c4d070dce75ed1b

Criterion: Across the manuscript, no scene uses Marlow House as its setting, and references to Marlow House occur only as a view from the quay or as mentions.

## Pass conditions

The manuscript must satisfy a negative constraint on Marlow House:

1. No scene of the manuscript is set inside Marlow House; no scene uses Marlow House as its setting.
2. Every reference to Marlow House in the manuscript occurs only as a view from the quay or as a mention, never as a scene the narration enters.
3. No passage places a character inside Marlow House, describes its interior, or narrates an event that takes place within it.

## Verdict contract

Pass only if the completed manuscript itself satisfies all pass conditions: Marlow House is never entered as a scene and is only seen from the quay or mentioned. Fail if any scene is set inside Marlow House, if its interior is described, or if a reference to it is anything other than a view from the quay or a mention. Fail also if the fact appears only in criteria files, planning notes, or source requirements rather than being honored by the manuscript.
