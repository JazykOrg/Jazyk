# crit_style_17_d5afe1c6

Criterion: Dialogue in the manuscript is enclosed in double quotation marks.

## Pass conditions

The manuscript must enclose all spoken dialogue in double quotation marks:

1. Every line of spoken dialogue in the chapter files is wrapped in double quotation marks ("..."), not single quotation marks ('...') or any other delimiter.
2. A reader can identify each utterance of dialogue by its double quotation marks.
3. No dialogue is set off with single quotation marks, guillemets, or unmarked speech.
4. The rule holds across every chapter, not just in isolated passages.

## Verdict contract

This is a positive, judgment-based criterion. It is judged by reading the manuscript chapter files:
- PASS when all spoken dialogue is enclosed in double quotation marks and no dialogue uses another delimiter.
- FAIL when any dialogue is set off with single quotation marks or another delimiter, or when dialogue is left unmarked.

When no chapter files exist yet, the manuscript is not generated and the criterion fails by design: it is the acceptance gate generation must clear.
