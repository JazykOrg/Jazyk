Criterion: Port Alder's setting inventory contains the ferry and the quay frontage as named setting elements.

## Pass conditions

The manuscript must establish the ferry and the quay frontage as named setting elements of Port Alder:

1. The manuscript identifies Port Alder as the setting.
2. The manuscript names the ferry as a setting element of Port Alder (the ferry serving Port Alder, the only way in besides a two-hour drive around the estuary).
3. The manuscript names the quay frontage as a setting element of Port Alder (the frontage granted to the Marlows by the Lantern Room lease for as long as the harbor wall stands).
4. No surrounding passage contradicts the ferry or the quay frontage being elements of the Port Alder setting.

## Verdict contract

Pass only if the completed manuscript itself satisfies all pass conditions. Fail if the ferry and quay frontage appear only in criteria files, planning notes, or source requirements, or if either is absent from the Port Alder setting in the manuscript.
