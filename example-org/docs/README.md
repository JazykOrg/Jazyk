# Ridgeline Outfitters

Ridgeline Outfitters is an outdoor gear retailer with about 120 employees, a warehouse in
Boulder, and four stores along the Front Range. These documents describe how the company
is organized and how its everyday processes work. They are the source of the Ridgeline
employee handbook.

## The company

Ridgeline Outfitters is made up of four departments:

- [Operations](departments.md#operations), which runs the warehouse and the stores.
- [Sales](departments.md#sales), which owns revenue and the wholesale accounts.
- [Finance](departments.md#finance), which keeps the books and runs payroll.
- [People](departments.md#people), which hires and supports employees.

Every department has a head. The head of a department is a manager.

## The handbook

The employee handbook is delivered as a set of markdown pages, one page per document in
this folder, under `handbook/`:

```
handbook/
  README.md
  departments.md
  hiring.md
  expenses.md
  policies.md
```

Each handbook page keeps the headings of its source document. The handbook opens with a
table of contents that links every page. A handbook page never mentions a form number or
a file path; those live in the intranet, not in the handbook.

## Documents

- [Departments](departments.md): the four departments, their roles, and their teams.
- [Hiring](hiring.md): how an application moves from applied to hired or rejected.
- [Expenses](expenses.md): how an employee gets reimbursed for money spent on company
  business.
- [Policies](policies.md): the rules that apply to every employee, and a glossary.
