# Project review (2026-11-07)

A read-only review of the whole repository, run as eight parallel reviews: store and parsing,
reconciler, sessions and tools, MCP, frontends, consumers, docs, and build and CI. Each item
names its evidence (`file:line` at master `6bbc7e6`). This file tracks what is done.

Status marks: `[ ]` open, `[x]` done (with the merge commit), `[?]` waits on an owner
decision (see [decisions](#decisions)), `[-]` dropped.

Work rules: one worktree and one local branch per work package, docs first for any behavior
change, `cargo test --locked` green before a merge, `git merge --no-ff` into local `master`.

Baseline: `cargo test --locked` 1003 passed, 3 ignored. `cargo clippy --all-targets` fails
on one deny lint. `cargo fmt --check` differs in 104 of 142 files. The WASM check passes with
28 warnings. `go vet` and `go test` pass in `runtime-worker/`.
