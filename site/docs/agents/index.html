Two ways to use a coding agent

An agent can be the tool you already talk to, or the worker Jazyk starts for compiler sessions. These are separate roles. Choose the one that matches how you want to work.

Role How to connect Who starts the work
Your existing agent uses Jazyk tools MCP server You ask the agent to inspect or compile a set.
Jazyk runs an agent for its sessions ACP profile The compiler schedules a goal batch and starts the configured worker.

Give your existing agent Jazyk tools

In your project folder, launch the tool you use:

Example · Claude Code 
jazyk launch claude

The launcher also accepts codex, cursor, and gemini. The chosen tool must be installed. It checks setup and adds a Jazyk MCP entry without replacing unrelated configuration.

For setup without launching, use jazyk init --mcp cursor, with your client’s name. For a client you configure by hand, give it this server command and the project as its working directory:

MCP server command 
jazyk mcp all
Example · request to your coding agent 
List the document sets in this project. Inspect the Main set and show
its open questions. Compile Main, then explain what still needs my decision.

The agent uses compiler tools to claim and resolve work. Name the document set so it does not have to guess your write target.

Use an agent as the compiler worker

Init offers codex, claude, and opencode. To choose a profile in an existing project:

Terminal 
jazyk init --agent claude

The agent must already be installed and authenticated. Claude and Codex profiles use ACP adapters launched with npx, so Node.js and adapter network access are needed. The external agent brings its own model; embedded-agent endpoint settings do not choose that agent’s model.

Run jazyk benchmark from the project before using a new agent. Then use jazyk compile --set Main or your GUI’s Build.

Give it intent and keep decisions visible

Ask the agent to clarify the docs and resolve compiler work. When an assumption changes the product, make it explicit in the prose or review its proposal. A freeform chat promise is not recorded verification evidence.

The graph tools use loaded context and validated changesets. An agent resolving compiler goals cannot create or prioritize new goals; the harness derives those from the project state.
