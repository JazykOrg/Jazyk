Commands for compiler work.

Select the right set, run the next stage, and inspect what happened.

On this page

Select a project and document set

Run commands inside a project folder. Discovery walks up to the nearest .jazyk/jazyk.toml. Aggregate reads show all sets. A graph operation targets a named set or its immutable ID.

Terminal 
jazyk sets list
jazyk compile --set Main
jazyk status

Bare jazyk compile runs dirty sets in configuration order. A mutation such as generation or answering a diagnostic needs a set selector unless there is exactly one set.

Commands by task

Task Command Effect
Initialize jazyk init Create project configuration and offer agent/editor setup.
Select documents jazyk sets add Main --docs 'docs/**/*.md' Add a named set.
Update a selection jazyk sets update Main --source 'src/**' Update the provided selection fields.
Compile jazyk compile --set Main Reconcile docs and graph.
Watch jazyk watch --set Main Recompile saved changes.
Check jazyk check --set Main Compile and fail on open error diagnostics or incomplete work.
Generate jazyk gen --set Main Bind and generate the deliverable.
Verify jazyk test --set Main Evaluate recorded tests and criteria.
Audit jazyk test --set Main --audit Rebuild ledger bindings from artifact markers without running tests.
Draft docs jazyk decompile src --set Main Draft prose from selected unclaimed source.
Browse locally jazyk gui Start the local API and open jazyk.dev.

Inspect without guessing

Command What you learn
jazyk status --costs Verdict, work counts, and recorded cost.
jazyk preview --set Main The next session’s assembled prompt.
jazyk explain <goal-or-target> --set Main Why work exists or what a target change opens.
jazyk ripple <root> --set Main [--back] The causal chain in the journal.
jazyk context <target> --set Main The context the load tool renders.
jazyk query <text> --set Main Matching entities.
jazyk docsgen --set Main Graph documentation and diagram pages.
jazyk viewer --set Main An offline graph snapshot.

Useful options

Option Meaning
--set NAME_OR_ID Target one document set.
--sessions N on compile Bound the run to N sessions. Zero derives work without LLM calls.
--verbose, -v Include prompts, payloads, and the goal cascade.
--quiet, -q Show board summary, GC burst lines, and verdict.
--agent NAME Choose the worker profile for this run.
--model MODEL Override the embedded agent’s model.
--llm-base-url URL Override its endpoint.
--json where supported Use structured output. Consult command help.
--help, -h Show command-specific usage and exit codes.

Arguments shown in angle brackets are placeholders. Replace them before running. Options in square brackets are optional; do not type the brackets.

Bounded work and automation

Terminal 
jazyk compile --set Main --sessions 1
jazyk compile --set Main --sessions 0
jazyk compile --help

A bounded run can stop incomplete after committed progress. Compile exits zero when its selected work converges, one when incomplete, and two on usage or configuration errors. Check can call AI because it runs compilation.

Use each command’s help for its exact argument and exit contract. Commands such as init have their own meanings for nonzero codes.
