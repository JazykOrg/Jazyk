SEMANTIC GRAPH

Compilation

Build stages, agent sessions, validated commits, and convergence.

On this page

Running compilation

jazyk compile brings each selected document set’s graph into line with its documents. It can call the configured agent. With no selector it processes dirty sets in configuration order.

Terminal 
jazyk compile --set Main

Compilation establishes the semantic model. Producing a deliverable and evaluating its tests are later operations.

Build stages

  1. Parse and align

    The harness reads sections, compares them with stored state, and relocates anchors. Unchanged material does not need another extraction session.

  2. Derive the work

    The compiler derives goals from docs, graph, history, and evidence. It orders and groups ready work. The model resolves a goal; it does not invent the schedule.

  3. Reconcile and judge

    Agent sessions extract facts and compare meaning. Validated mutations commit as a changeset. Ambiguities and contradictions become findings rather than silently disappearing.

  4. Derive and render

    Commits recompute relationships, state machines, and default views. Native rendering projects those views into diagrams.

  5. Check the result

    Deterministic checks assess coverage, references, stale provenance, conformance, and other invariants. The final verdict reports mandatory work and human-blocked or optional counts.

Goals and sessions

A goal is work the harness derives from project state, such as reconciling a section or reviewing an entity. Goals are not a stored task list. The board derives readiness, blockers, and batches on each update.

The model extracts and judges meaning. The harness owns identity, scheduling, budgets, write validation, derived data, and commit. A session resolves or fails its assigned goals and records a justification. It cannot create or prioritize goals.

One build holds a lease, and one agent session runs at a time. A successful changeset commits atomically and records a journal generation.

Reading the verdict

Verdict Meaning
Converged No open or failed mandatory work remains and the checks pass. Read diagnostic, blocked, and optional counts too.
Incomplete Mandatory work remains, failed, or was parked at a limit. Read its reason and resume from committed state.

Convergence describes compiler work. It does not certify every generated artifact, settle every human question, or erase standing diagnostics.

Previewing and bounding work

Terminal 
jazyk preview --set Main
jazyk compile --set Main --sessions 1

Preview shows the next assembled session prompt. A session limit bounds a run without disguising unfinished work. A no-op rebuild opens no goals and makes no LLM calls.
