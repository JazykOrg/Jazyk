WORK WITH CHANGE

Make the decisions visible.

Resolve ambiguity and trace whether a fact is stated, inferred, or decreed.

Questions are part of the compiler result

Two docs may give different bounds. A requirement may omit the failure behavior. Generation may need a product choice that the prose never made. These are findings for the owner to judge.

A diagnostic is a persistent record, not a temporary message. It retains identity across builds. Human triage survives recompilation.

Finding Useful response
Contradiction Decide which rule holds, or name the distinct conditions that make both valid.
Ambiguity Clarify the subject, condition, value, or expected outcome.
Invented choice Review the choice made to fill missing intent and state the accepted rule.
Pending proposal Accept the prose addition, revise it, or retract the fact.

Ask where a fact came from

Provenance Origin What to review
Quote Verbatim source text, located in a document section. Does the sentence support the fact as recorded?
Derived Inference from named facts with reasoning. Is the inference valid, and should it become explicit prose?
Decree A human write on the graph. Should the docs state this decision?

Derived and decreed facts carry ratification proposals. Accepting one puts the sentence in the docs and changes the fact’s provenance to quote. Identity is preserved. A quote is evidence of what the docs state, not proof that the product implements it.

Answer at the point of uncertainty

Use Inbox in the GUI, diagnostic actions in your IDE, or jazyk answer in the terminal. Read the proposed edit before choosing it.

Example · replace the diagnostic ID 
jazyk answer diag:your-id --set Main
jazyk answer diag:your-id --set Main --text 'The 21-day rule applies to retail Orders.'

An edit option applies a suggested prose and graph change. A freeform answer records your reply for an answer session to handle. Check its resulting state and inspect the affected docs.

You can also edit the prose directly. Make the scope explicit if different Order kinds intentionally follow different rules. Then compile again.

Triage is not the same as fixing the docs

Acknowledging, suppressing, or marking a finding won’t-fix records your judgment. It does not rewrite the conflicting statements or establish verification evidence.

Use triage deliberately and keep its context. If the stated obligation changed, revise the docs. If a fact should not exist, retract it rather than accepting wording you do not mean.
