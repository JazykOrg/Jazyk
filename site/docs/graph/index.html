A persistent model of meaning

The graph is edited in place as the docs change. It is not a fresh summary regenerated on each run. Authored nodes keep their IDs through renames and updates; a merge leaves a redirect to the surviving node.

Every fact has provenance: a quote from the documents, an inference with its reasoning, or a human decree. Inferences and decrees carry proposals toward prose so the docs can catch up.

Follow one sentence through the model

ILLUSTRATION / ORDERLY

Orderly cancels an unpaid Order at the start of day 22 after placement.
Entities
Orderly and Order, the named subjects.
Requirement
The cancellation obligation, linked to its verbatim source quote.
Criterion
An unpaid Order at the start of day 22 is cancelled, from a concrete example or a reviewed proposal.
Transition
The Order moves from placed to cancelled under the stated condition.
State machine
The transition contributes to the Order’s derived state machine.

This illustrates the model; it is not output from a compiler run. Read your actual graph to see the facts its sessions recorded.

The pieces you will inspect

Piece What it records
Entity A thing the docs name, its attributes, and one containment parent.
Requirement One freeform obligation, its entities, directional edges, transitions, and facets.
Criterion Observable evidence for one requirement. Tests bind to criteria.
Relationship Connections derived from requirement edges.
State machine States and transitions derived for a subject entity.
View Which members and query a diagram includes, not its visual layout.
Section Document structure and coverage.
Diagnostic A persistent finding, question, proposal, or judgment.

What a compile does

  1. Parse and align

    The harness reads sections, compares them with stored state, and relocates anchors. Unchanged material does not need another extraction session.

  2. Derive the work

    The compiler derives goals from docs, graph, history, and evidence. It orders and groups ready work. The model resolves a goal; it does not invent the schedule.

  3. Reconcile and judge

    Agent sessions extract facts and compare meaning. Validated mutations commit as a changeset. Ambiguities and contradictions become findings rather than silently disappearing.

  4. Derive and render

    Commits recompute relationships, state machines, and default views. Native rendering projects those views into diagrams.

  5. Check the result

    Deterministic checks assess coverage, references, stale provenance, conformance, and other invariants. The final verdict reports mandatory work and human-blocked or optional counts.

Inspect meaning before generating

Check entity boundaries, requirement wording, and criteria. Follow a quote back to its sentence. Ask whether a diagram’s connection is supported by a requirement. Review any inferred facts that need to become explicit prose.

The graph is also the contract consumed by generation, verification, docs generation, and agent retrieval. A mistake here can affect every downstream result.
