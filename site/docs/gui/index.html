INSTALLATION

Local GUI

Connect the browser editor to a local compiler, or open a browser folder.

On this page

Use the GUI with a local compiler

From your configured project folder, run:

Terminal 
jazyk gui

Jazyk starts an API on your computer and opens jazyk.dev with its connection details. Keep the terminal process running. Files, graph state, and compilation stay on your computer. The browser page is the interface; a Cloud account is not required.

Use Docs to edit the prose, Model to inspect the graph, and Inbox to review questions and proposals. Select the intended document set in Build. The editor’s Build groups compilation, generation, and review when those stages have work.

Open a folder directly in the browser

At jazyk.dev, choose Local folder. A compatible browser can ask you to select a directory. Other browser projects may use browser storage instead. Read the project menu’s saved-location message so you know where your edits go.

A browser-only project runs the portable compiler in the tab. It needs a model before it can build. It does not gain your terminal agent simply because that agent is installed on your computer. Use the local API path above when you need the native compiler and its configured agent.

Check capabilities before expecting a result

Demos include compiled state you can inspect. Browser and native backends differ in supported input formats, model access, and rendering. The editor shows unavailable actions with their reason.

Connection and recovery

If the local process stops, start jazyk gui again and use the link it opens. Allow the browser’s local-network access prompt if it appears. Check that the project shown is the folder you intended.

jazyk gui --no-open prints the connection address without opening a tab. --port N selects a port; the normal startup finds an available port. For automatic local compilation after saved edits, use jazyk gui --watch. The default is an explicit build action.
