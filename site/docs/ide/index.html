IDE setup

Configure inline diagnostics, navigation, and the Jazyk chat agent.

Before you connect

Install the CLI, make jazyk available to your editor, and create a document set. Compilation also needs a configured agent or model.

Choose how Jazyk fits your editor

You can read the graph inline, run Jazyk as a chat agent, or give your existing coding agent Jazyk tools. These integrations can work together.

You want… Use What it does
Diagnostics and navigation in prose Language support (LSP) Reads the last compiled graph. Shows diagnostics, entity hovers, definitions, references, and requirement links.
Jazyk in the editor’s agent panel Jazyk agent (ACP) Runs your configured downstream agent with Jazyk tools, build commands, and project context.
Your existing agent to inspect or compile Jazyk tools (MCP) Makes the graph and lifecycle tools available to Claude Code, Codex, Cursor, or another MCP client.

VS Code: inline language support

Run the launcher from the project folder:

Terminal 
jazyk launch vscode

The launcher configures MCP and registers the ACP entry. It checks for the jazyk.jazyk language extension and prints an install hint if it is missing. The ACP entry needs a separate ACP client extension in VS Code; the language extension handles inline support.

Build the language extension from source

The extension lives in your Jazyk checkout. You need Node.js and npm.

Terminal · replace the checkout path 
cd /path/to/Jazyk/bootstrap/editors/vscode
npm install
npm run compile

Open that extension folder in VS Code and press F5 to launch an Extension Development Host. In the new window, open your project folder. This is the development setup for the extension, not a Marketplace install.

If the binary is not on the editor’s PATH, set jazyk.server.path to its absolute location in VS Code settings.

Zed and JetBrains: the Jazyk chat agent

Register Jazyk with the editor you use:

Terminal · Zed 
jazyk acp install zed
Terminal · JetBrains 
jazyk acp install jetbrains

Open your project and choose Jazyk in the editor’s ACP agent picker. Registration is global; the opened project supplies its own configuration. You can also use jazyk launch zed or jazyk launch jetbrains to check setup and open the folder.

In the Jazyk chat, ask about a requirement or use its commands:

Jazyk agent chat 
/status
/preview
/compile
/questions

/compile reconciles documents with the graph. /questions lists decisions waiting for you. /generate and /verify handle the deliverable when source paths are selected.

Chat support and inline support are separate

Registering the chat agent does not install a language server. For inline support in another LSP-capable editor, configure it to launch jazyk lsp over stdio in your project.

Keep your existing coding agent

Use the launcher to connect Jazyk tools and start your usual tool:

Terminal · Cursor 
jazyk launch cursor

The same launcher accepts claude, codex, and gemini. The chosen program must already be installed. Setup merges a Jazyk MCP entry instead of replacing the rest of your configuration.

To set up a client without launching it, use jazyk init --mcp cursor. For a client you configure by hand, run the server with:

MCP server command 
jazyk mcp all

Set its working directory to your project. Ask the agent to inspect the document sets and compile the intended set. The slash commands above belong to the Jazyk ACP agent; another agent uses the MCP tools exposed to it.

The everyday editing loop

  1. Edit and save the prose

    Keep obligations and concrete examples in the docs. Save before asking Jazyk to compile the change.

  2. Compile deliberately

    Use /compile in the Jazyk agent, or jazyk compile --set Main in a terminal. Use jazyk watch --set Main when you want saved edits to recompile automatically.

  3. Read what the sentence became

    With language support connected, hover an entity to read its definition and diagram. Hover a requirement’s quote to inspect its statement and any recorded code and test evidence. Follow definitions and references across documents.

  4. Answer or revise

    Review inline diagnostics. A diagnostic with options can offer code actions; the VS Code extension also provides Jazyk: answer for a text reply. You can revise the prose directly, then compile again.

When something looks wrong

No diagnostics or hovers

Check that the document belongs to a set and that the set has been compiled. The language server reads the stored graph; opening a file does not call the AI.

Diagnostics still describe old text

Save and compile the affected set. The language server refreshes after a committed graph change. If it stays stale, inspect the Jazyk output channel and restart the language server.

The IDE cannot find jazyk

GUI applications may have a different PATH from your terminal. Set the binary’s absolute path in the LSP configuration, or jazyk.server.path in VS Code. Register the ACP agent again from a terminal where the binary is available.

The Jazyk chat agent fails to start

Check the selected agent and its authentication. Confirm Node.js is available if its profile uses an npx adapter. Run jazyk benchmark in the project terminal to test the configured agent and model.
