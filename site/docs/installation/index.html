GETTING STARTED

Installation

Install Jazyk locally or use Cloud. Configure a workspace and run a first compile.

Local and Cloud workspaces

Workspace Files Compilation Setup
Local Your computer Your agent or model Install the compiler below.
Cloud Hosted project Included AI Sign in at jazyk.dev.
Browser folder Selected folder or browser storage A model configured in the editor Open the browser editor.

Local use needs no Cloud account. Signing in does not upload your local folder. Choose storage and AI access deliberately.

Building the local binary

You need Git and a current Rust toolchain. Build from the public source repository:

Terminal 
git clone https://github.com/JazykOrg/Jazyk.git
cd Jazyk/bootstrap
cargo build --release
export PATH="$PWD/target/release:$PATH"
jazyk --help

The export applies to this terminal. Add the absolute release directory to your shell configuration for later sessions. A GUI editor may need the binary path set explicitly.

Project and document-set setup

Run this from a new project folder. Init asks about agent and editor setup. Keep existing documents if you already have them.

Terminal 
jazyk init
mkdir -p docs

Create docs/main.md and describe one small behavior. Then tell the compiler which files belong to your subject:

Terminal 
jazyk sets add Main --docs 'docs/**/*.md' --roots docs/main.md

Init creates .jazyk/jazyk.toml with no sets. Adding Main selects your documents. Quote globs so the shell passes them to Jazyk.

First compilation

Local compilation needs an installed and authenticated coding agent, or the embedded agent with a configured model endpoint. Init offers both paths. A connected endpoint alone is not proof that its model can do the work.

Terminal 
jazyk benchmark
jazyk compile --set Main
jazyk status

Benchmark checks the configured agent or model. Compile builds the graph from your docs. Read any questions and remaining work beside the verdict, then inspect the result in your editor.
