REFERENCE

Choose AI you can evaluate.

Configure session execution, test capability, and inspect quality and cost on a small subject.

Choose who runs the sessions

The embedded agent calls an OpenAI-compatible endpoint. An external agent runs through an ACP profile and brings its own model and authentication.

Choose an external agent if it is the coding tool you already trust and have configured. Choose the embedded agent when you want direct control over endpoint and model settings. Neither path requires a Cloud account for local work.

Cloud uses its included AI and available service capabilities. Your local endpoint settings do not configure a Cloud project’s hosted worker.

Configure the embedded agent

Put machine defaults in ~/.jazyk/config.toml. This is an example, not a recommended model ID:

Example · global configuration 
[llm]
base_url = "http://localhost:11434/v1"
model = "your-model-id"
api_key_env = "JAZYK_API_KEY"

Use the URL and model your server serves. For a hosted provider, set its compatible endpoint and keep the API key in the named environment variable. Do not track credentials in project files.

Understand which setting wins

Resolution is per field, from highest to lowest priority:

  1. CLI flags.
  2. Environment variables such as JAZYK_MODEL and JAZYK_LLM_BASE_URL.
  3. The set’s settings.
  4. Project settings.
  5. Global machine settings.
  6. Built-in defaults.

An environment variable can explain why changing the project’s model had no effect. External agents ignore embedded-agent model settings and use their own configuration.

Test session capability first

Terminal 
jazyk benchmark

Run this before trusting a new model. It grades whether the configured agent can use tools, obey contracts, and complete the tested sessions. It is not a guarantee of judgment quality on every project.

The embedded agent is measured with native and text codecs. A model can pass one and fail the other. Native uses the endpoint’s tool-call support; text uses the text representation. External agents are measured through their own agent path.

Inspect failures and recorded rounds, tokens, and checks. An endpoint that returns prose is not necessarily a model that can resolve compiler goals. Small local models can fail capability tests.

Separate capability from judgment

After the benchmark, try a small document set whose meaning you understand. Inspect extracted obligations, missing facts, contradictions, and criteria. A session that passes its gate can still make a weak judgment.

Use the same input to compare models and inspect evidence rather than confidence in the reply. More capable models may be worth using for abstraction and cross-requirement judgment even when a cheaper one extracts simple facts adequately.

Executor overrides can choose profiles by goal kind or class. Keep that an advanced tuning step until one configuration produces useful results.

Control work with scope and visibility

Start with a focused set and a bounded run. Read a preview before broad changes. Use jazyk status --costs and transcripts to understand where sessions and tokens went.

Terminal 
jazyk compile --set Main --sessions 1

Compile sessions are sequential. A paused or incomplete run retains committed progress. Session and build budgets belong to the compiler’s limits registry, not arbitrary project tuning fields.

A no-op rebuild makes no LLM calls. Repeated runs are not a substitute for resolving a failed goal, unavailable endpoint, or unstable decision.
