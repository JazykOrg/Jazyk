Know what belongs in the project.

Reference named sets, selection rules, persistent state, and the files to track in Git.

Project configuration lives in .jazyk

.jazyk/jazyk.toml declares the project. Paths resolve from its containing project folder, not from the metadata directory. This example uses the current named-set schema:

Example · .jazyk/jazyk.toml 
version = 1

[[sets]]
id = "ds_main"
name = "Main"
docs = ["docs/**/*.md", "!docs/archive/**"]
roots = ["docs/main.md"]
source = ["src/**", "tests/**", "package.json"]

Each ID is immutable and unique, with the ds_ prefix. Renaming a set changes its display name, not its graph identity. Prefer jazyk sets or the editor’s Document sets controls for ordinary selection changes.

How selections match

  • Exact paths and globs can be mixed.
  • ! excludes; later matches override earlier ones.
  • Overlapping document selections compile independently in each set.
  • Empty source selection disables bind, generation, and verification work.
  • Docs selected by any set are excluded from source write scopes in every set.
  • Compiler state, Git metadata, caches, and nested project boundaries are excluded.

Source globs name allowed product paths. Their files may not exist yet, so a warning can report a pattern with no matches. Inspect selection previews and overlaps before broadening access.

What is stored where

Layout · selected directories 
.jazyk/
  jazyk.toml              Project settings and named sets
  .gitignore             Rules for generated state
  sessions/              Project-wide user conversations
  runs/                  Grouped job records
  ds_main/
    graph/               Persistent semantic graph shards
    docs/                Section trees and coverage
    journal/             Committed changesets by generation
    diagrams/            Rendered views
    gen/                 Generation and verification metadata
    trace/               Build transcripts
    status.yaml          Verdict, change records, and costs

The graph is persistent local state. Renderings are projections of it. Do not delete state merely to make a finding disappear; first inspect its cause and recovery options.

Track the authored contract

Track the docs, source files, .jazyk/jazyk.toml, and .jazyk/.gitignore. Keep generated state and secrets ignored. The metadata ignore file can allow just the config and ignore file:

Example · .jazyk/.gitignore 
*
!jazyk.toml
!.gitignore

If the outer repository ignores the entire .jazyk directory, inner exceptions cannot rescue the config. Narrow that parent rule. Machine defaults belong in ~/.jazyk/config.toml; that file does not mark a project.

Settings change execution, docs define intent

Project defaults can configure agents, endpoints, executors, workflow, and linting. Set-specific values override inherited settings. Model values resolve through the full precedence order.

The config selects inputs and where work may write. State the deliverable’s medium, content, and required technology in the documents so they become graph obligations.
