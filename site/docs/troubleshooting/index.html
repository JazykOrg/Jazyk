Troubleshooting

Resolve missing input, incomplete builds, stale evidence, and connection problems.

On this page

Inspecting the current state

Read jazyk status, the build thread, or Inbox. Identify the set, the remaining work, and the actual reason. Committed progress survives incomplete runs.

For a surprising goal, use jazyk explain. For a surprising cascade, use jazyk ripple. Inspect the next prompt with jazyk preview before running a larger retry.

No documents or unexpected input

No document set exists

Init creates an empty set list. Add a set with jazyk sets add Main --docs 'docs/**/*.md', or use Document sets in the editor. Browsing files alone does not select compiler input.

The set matches zero files

Check paths relative to the project root, exclusions, and spelling. Quote CLI globs. Read jazyk sets list and the selection warnings.

Unsupported input or parse error

Check the backend’s format support and whether the file is readable. Native and browser formats differ. An empty or unreadable file is not a successfully compiled subject.

A build does not finish

Incomplete after a bounded run

A session limit or budget can stop the run after real progress. Read the parked or failed reason, fix it if necessary, then compile the same set again.

Work is blocked on a human

Review the diagnostic’s question or proposal. Answer or revise the prose. Retrying cannot supply your intent.

Agent or endpoint unavailable

Verify the agent’s installation and authentication, or the embedded endpoint and model. Check higher-priority environment settings. Use jazyk benchmark after recovery.

Model keeps producing weak or invalid work

Read its benchmark results and test a small known subject. Check the codec and session transcript. Select a model capable of the work before blaming the prose alone.

The result looks complete but is not verified

A graph converged, but evidence is missing

Convergence is the compiler checkpoint. Select the source files, inspect bindings and criteria, and run verification. Read which criteria have current results.

A previous pass became stale

Code, tests, or the underlying criteria changed. Rerun verification. Inspect the changed inputs rather than treating the old pass as current.

A deck, site, or artifact is only described in prose

Check the documented medium and generation result. The requested artifact must actually be built and inspected; a description or placeholder does not satisfy it.

Editor state and connections

No IDE diagnostics or hovers

Verify that language support is running, the file belongs to a set, and the set has been compiled. The LSP reads the graph and does not compile on opening a document.

The GUI cannot connect locally

Keep jazyk gui running, reopen its connection link, and allow local-network access if requested. Confirm the selected project root.

Cloud sign-in expired or a save was interrupted

Keep the tab open. Sign in with the same account and inspect the recovered draft in the same project before closing it. Recovery storage depends on browser availability.
